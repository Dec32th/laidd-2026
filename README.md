# laidd-2026
# AI 기반 신약 후보물질 독성 최적화 에이전트

**제4회 AI 신약개발 경진대회 (4th JUMP AI, 2026)** 참가 프로젝트

## 개요

이 리포지토리는 두 가지 목적을 함께 가집니다.

1. **공모전 제출물** — 보건복지부·한국보건산업진흥원 주최 [제4회 AI 신약개발 경진대회(JUMP AI)](https://www.laidd.org/mod/ubboard/article.php?id=1&bwid=879)의 **"도구 활용 기반 분자 최적화 루프"** 분야 참가작. 후보 화합물의 독성을 예측하고, 문제가 되는 구조를 자동으로 개선한 뒤 다시 평가하는 **에이전틱(agentic) 최적화 루프**를 구현합니다.
2. **2026년 LAIDD 학습 기록** — 공모전 준비를 계기로, [LAIDD(AI 신약개발 교육 플랫폼)](https://www.laidd.org)의 강의들을 2026년 한 해 동안 꾸준히 수강하며 정리하는 학습 로그이자 포트폴리오. AI 신약개발 대학원 진학(단백질·화합물 분석 분야)을 목표로 한 장기 학습 과정의 일부입니다.

> 예선 접수: ~2026.08.07 / 본선: 2026.09.07 ~ 10.02 / 최종 발표: 2026.11.06

## 프로젝트 목표

독성이 우려되는 화합물을 입력받아, 다음 과정을 자동/반복적으로 수행하는 파이프라인을 개발합니다.

```
[화합물 입력]
     │
     ▼
① 독성 예측 (Tox21 기반 모델)
     │  → 12개 독성 엔드포인트에 대한 예측 확률 산출
     ▼
② 구조 개선 (RDKit)
     │  → FilterCatalog 기반 문제 구조(PAINS 등) 탐지
     │  → 규칙 기반 치환(substitution rule)으로 구조 수정
     ▼
③ 재평가
     │  → 수정된 구조를 다시 ①에 입력, 독성 개선 여부 확인
     ▼
[반복 또는 최종 후보 산출]
```

이 루프를 통해 사람이 수작업으로 반복하던 "예측 → 수정 → 재검증" 과정을 에이전트가 자율적으로 수행하도록 하는 것이 핵심 아이디어입니다.

## 사용 데이터 및 도구

| 구분 | 내용 |
|---|---|
| 독성 데이터셋 | [Tox21](https://tripod.nih.gov/tox21/challenge/) — 12개 독성 엔드포인트(NR/SR 경로 등) 라벨링된 화합물 데이터 |
| 분자 처리 | [RDKit](https://www.rdkit.org/) — 분자 구조 파싱, 기술자(descriptor) 계산, FilterCatalog(PAINS/Brenk 등) |
| 개발 환경 | Google Colab (Python) |
| 언어 | Python 3.x |

## 학습 및 개발 로드맵 (예선 마감 8/7까지)

방학 기간을 활용해 아래 순서로 학습과 구현을 병행합니다. 각 주차는 "무엇을 공부하는지"와 "무엇을 구현하는지"를 함께 정리했습니다.

### 1주차 (7/13 ~ 7/19) — RDKit 기초 다지기

- **공부할 것**
  - SMILES 표기법과 분자 객체(Mol) 다루는 법
  - 분자 기술자(descriptor) 계산 (분자량, LogP, TPSA 등)
  - FilterCatalog 개념 — PAINS, Brenk 등 구조 경보(structural alert) 필터
- **구현할 것**
  - Colab에서 RDKit 설치 및 예제 화합물로 SMILES ↔ Mol 변환 실습
  - FilterCatalog로 샘플 화합물의 "문제 구조" 탐지해보기

### 2주차 (7/20 ~ 7/26) — Tox21 데이터셋 이해 및 독성 예측 모델

- **공부할 것**
  - Tox21 데이터셋 구조 (12개 독성 엔드포인트: NR/SR 경로 등)
  - 분자 지문(fingerprint, 예: Morgan/ECFP)을 이용한 분자 표현 방법
  - 기본적인 분류 모델(랜덤포레스트, 간단한 신경망 등) 개념
- **구현할 것**
  - Tox21 데이터 로드 및 전처리 (결측치, 라벨 불균형 확인)
  - fingerprint 기반 baseline 독성 예측 모델 학습 및 평가

### 3주차 (7/27 ~ 8/2) — 구조 개선 루프 설계

- **공부할 것**
  - 관용적인 구조 치환 규칙(substitution rule)이 정리된 사례 조사
  - 에이전틱 AI 개념 — 자율적 반복(iteration), 도구 호출(tool-use) 설계 패턴
- **구현할 것**
  - FilterCatalog가 탐지한 문제 구조를 규칙 기반으로 치환하는 함수 작성
  - 독성 예측 → 구조 개선 → 재예측이 한 번 순환하는 최소 루프(prototype) 완성

### 4주차 (8/3 ~ 8/7) — 통합, 검증 및 제출 준비

- **공부할 것**
  - 제안서 작성 가이드 및 기존 수상작 사례 확인 (LAIDD 자료 참고)
- **구현할 것**
  - 전체 파이프라인(예측–수정–재평가) 통합 및 여러 화합물로 반복 테스트
  - 결과 정리(개선 전/후 독성 비교), 제안서 초안 작성 및 제출
