# 미팅 예시 3 — Meeko 기반 공유결합 도킹 검증 (노트북 58)

## 비교 결과

| 분자 | Best Inter+Intra Energy (kcal/mol) | 해석 |
|---|---|---|
| 오시메르티닙 (실제 EGFR Cys797 공유결합 억제제) | -5.31 | 안정 |
| 이타콘산 (공유결합 근거 없는 대조군) | +7.06 | 매우 불안정 |

12.4 kcal/mol의 뚜렷한 차이로 방법의 변별력 확인. 노트북 54에서 원자
매핑 문제로 실패했던 방식(SMILES-PDBQT 인덱스 직접 매핑)을 Meeko의
공식 지원 기능(결합차수 손실 없는 왕복 변환)으로 완전히 우회함.

## 개발 과정의 의미
1. 문제 발견(공유결합 미반영) → 2. 근사 시도 → 3. 원자매핑 문제로
정직하게 실패 인정 → 4. 저비용 대안(워헤드 참고표) 도입 → 5. 시간을
더 들여 올바른 도구(Meeko)로 재도전 → 6. 성공. 이 과정 자체가
연구방법론적 태도를 보여주는 사례.
