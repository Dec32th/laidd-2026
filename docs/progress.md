## 최종 수치 (test set 1174개, 1회성 최종검증 기준)

- 커버리지: 49.9%
- 완전 해결: 50%
- 최소 1단계 개선: 72%

valid set(1173개, 최신 코드)에서는 완전해결 규칙기반 74.5%,
토의 파이프라인 67~70%(실행 간 변동) — 자세한 내용은
docs/final_valid_set_comparison.md, docs/CHANGELOG.md 참고.

## 프로젝트 단계

1. **개발 (노트북 1-44)**: 커버리지 확장, 3-agent 아키텍처, 초기
   도킹/scoring 설계, 제안서 작성 및 JUMP AI 2026 제출
2. **공모전 후 확장 (노트북 45-57)**: 선례 라이브러리 확대, LLM
   토의 오케스트레이션, 도킹 자동화, 감사추적, 회귀테스트
3. **방법론 심화 (노트북 58-60)**: Meeko+AutoDock-GPU covalent
   docking 성공, 미팅 준비 자료 작성
4. **문서화/정리 (노트북 61-62)**: no_known_fix 재조사, README/
   CHANGELOG, LLM 비결정성 통합, 미팅 심화자료
5. **코드 정리 및 논문화 준비 (노트북 63-)**: 리팩터링, 학부연구생
   지원, 오픈소스 공개 준비
