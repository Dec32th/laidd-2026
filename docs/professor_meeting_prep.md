# 9월 10일 교수님 미팅 준비 — ToxGuard 프로젝트

경희대 ML 교수님 피드백 미팅용 정리. 대학원 지원(이도헌 교수님 KAIST,
이형기 교수님 SNU CCADD/CAIDD) 포트폴리오 맥락 고려. 구현 상세는
professor_meeting_deep_dive.md 참고.

## 프로젝트 현황

Tox21 데이터셋의 분자에서 독성 구조(toxicophore)를 자동 진단하고,
화학적으로 타당한 치환을 제안·검증하는 파이프라인. RDKit 규칙 기반
진단 + LLM 기반 토의(proposer-critic) 검증 + 단백질 도킹/합성용이성
정량 근거를 결합.

JUMP AI 2026 공모전(4th JUMP AI competition, 팀명 MorForge)에 제출,
예선 탈락 확정. 예선 결과와 무관하게 지속 개발해 오픈소스 공개 또는
대학원 진학 포트폴리오로 쓸 계획이었고, 실제로 예선 이후에도 계속
개선 작업을 진행함. README.md, CHANGELOG.md 정리 완료.

## 최종 수치 (valid set 1173개, 최신 코드 기준)

| | 예선 제출 | 규칙 기반 | 토의 파이프라인 |
|---|---|---|---|
| 완전해결 | 52.0% | 74.5% (874/1173) | 67.1~69.7% (실행 간 변동) |

핵심: 규칙 기반이 토의 포함 버전보다 수치가 높은 건 성능 저하가
아니라 의도된 트레이드오프 — 토의가 화학적으로 의심스러운 자동 치환을
막아서 표면적 성공률은 낮아지지만 각 성공의 신뢰도가 올라감.

## 설명할 구체 사례

1. Aliphatic_long_chain 재설계: BRENK 필터의 실제 SMARTS를 직접
   분석해 원소 종류와 무관한 순수 위상학적 패턴임을 밝히고, 에테르
   삽입 대신 분기(branching) 전략으로 전환해 완전해결.
2. Michael_acceptor_1의 EGFR 오귀속 편향 발견: 도킹 근거를
   critic에게 줬더니, 규칙과 무관한 벤치마크 표적(EGFR)인데도
   "이 분자는 EGFR 표적"이라고 잘못 단정하는 시스템적 편향을 발견,
   caveat 필드로 표적 특이성 근거 유무를 명시하도록 수정.
3. 공유결합 근사 시도 — 정직한 실패와 재도전 성공: 표준 도킹이
   공유결합 형성을 반영 못 하는 한계를 거리 기반으로 근사하려 두 차례
   시도했으나 원자 순서/결합차수 정보 손실로 둘 다 실패, 정직하게
   폐기하고 저비용 대안(워헤드 반응성 참고표, 이타콘산이 실제로
   KEAP1/GAPDH와 공유결합하는 내인성 대사물질이라는 문헌 사례 포함)을
   대신 도입. 이후 Meeko+AutoDock-GPU로 근본 해결 재시도 — receptor
   준비, tethered 리간드 준비, autogrid4/AutoDock-GPU 실행까지 전
   과정 성공. 오시메르티닙 -5.31 kcal/mol(안정) vs 이타콘산 +7.06
   kcal/mol(불안정)로 12.4 kcal/mol의 뚜렷한 차이 확인. 다만 Colab
   환경에서 AutoDock-GPU를 매 세션 재컴파일해야 하는 운영 비용이 커서
   상시 통합은 보류, 검증된 수치를 워헤드 참고표의 구체적 근거로
   흡수하는 절충안 채택.
4. LLM 비결정성 발견과 완화, 그리고 정직한 검증 한계: 같은 입력에
   토의 판정이 매번 달라짐을 200~1173개 규모 실험에서 확인, N회 반복
   다수결(self-consistency) 방식(ask_llm_debate_fix_consistent)을
   실제 파이프라인에 통합 완료. 다만 50개 소규모 재검증에서는 토의
   트리거 자체가 3건뿐이라 효과를 통계적으로 증명하지 못함 — 기능은
   완성했으나 기본값은 꺼둔 상태로 정직하게 남김.
5. 파괴적 편집 가드: 다중문제 충돌조정 알고리즘이 분자를 통째로
   파괴(원자 최대 93% 손실)해 우연히 단순해진 candidate를 "최선"으로
   착각하는 위험을 300개 샘플 스캔으로 발견하고 가드 추가. 이후 임계값
   민감도 분석으로 이 가드가 넓은 범위(0.3~0.7)에서 안정적임을 확인.
6. no_known_fix 재조사와 예전 결정의 재검증: 처리 불가로 남은 규칙
   중 iodine(덱스트로티록신/아미오다론 근거), 페노티아진 골격(9개
   승인 항정신병약 근거)이 실제로는 화학적으로 중요한 스캐폴드임을
   확인해 선례로 기록. 특히 iodine은 과거 "alkyl_halide와 100% 중복"
   이라는 결론이 있었으나 현재 데이터로 재검증한 결과 11건이 실제
   단독 gap임을 발견 — 과거 결정을 맹신하지 않고 재검증한 사례.
7. 경량 covalent docking 캐싱 설계 후 기각: 대표 케이스 도킹 결과를
   캐시해 다른 분자에 재사용하는 방안을 검토했으나, 이는 노트북 53의
   EGFR 오귀속 편향과 같은 종류의 함정(한 분자의 결과를 다른 분자의
   증거처럼 취급)이라고 판단해 기각. 대신 구체적 수치를 문헌적
   참고자료 서술에 흡수하는 방식으로 정직성을 지킴.

## 먼저 인정할 한계

- LLM 비결정성: 다수결 완화 기능은 만들었으나 대규모 검증 전이라
  기본값은 비활성
- 그리디 휴리스틱의 정당화: 충돌조정/파괴적편집 임계값은 데이터로
  안정성은 확인했으나, 이론적으로 엄밀히 유도된 값은 아님
- 공유결합 도킹은 방법론적으로 검증됐으나 운영비용 문제로 상시
  파이프라인에는 미통합
- phosphor 규칙의 P=S 서브클래스: 유기인계 농약 골격으로 확인되어
  치료용 약물 개선이라는 파이프라인 목적 범위 밖으로 판단, 처리 보류
- iodine, 페노티아진 골격 등 화학적으로 중요한 일부 규칙은 아직
  실제 치환 candidate(코드) 없이 선례 기록만 되어 있음
- 사람 최종 검토 라이브러리(연구자 피드백 구조화)는 본인이 화학
  전문가가 아니라 직접 만들 수 없어 폐기

## 교수님께 여쭤볼 질문 (우선순위순)

1. 예선 탈락이라는 결과와 별개로, 이 프로젝트가 대학원 지원용
   포트폴리오로서 어떤 부분이 강점이고 무엇을 더 보완해야 할지
2. LLM을 화학적 판단의 검증자(critic)로 쓰는 구조 자체가 독립적인
   연구 주제로 발전할 수 있을지, 아니면 어디까지나 도구적 장치로
   남는지
3. self-consistency(다수결)로 완화한 LLM 비결정성이 이 정도로
   충분한지, 아니면 더 엄밀한 방법(불확실성 정량화, 여러 모델 앙상블)
   이 필요한지
4. 그리디 휴리스틱(임계값 등)의 방법론적 타당성 — 데이터 기반 안정성
   확인 외에 더 엄밀하게 정당화하는 방법이 있는지
5. 목표 랩(이도헌 교수님 KAIST, 이형기 교수님 SNU)의 연구 방향과
   이 프로젝트의 정합성 — 이어서 무엇을 준비하면 좋을지
6. Meeko/AutoDock-GPU 기반 공유결합 도킹을 계속 발전시킬 가치가
   있는지, 아니면 지금처럼 참고표 방식으로 충분한지
7. (오픈소스 관련, deep_dive 문서 3장 참고) API 의존성 처리, 외부
   저작물 라이선스, 노트북 이력 공개 방식, 논문화 시 요구되는
   검증 수준에 대한 조언

## 대화 나눌 만한 주제 (질문 형태가 아니어도 되는 것들)

- 예선 탈락 이후에도 프로젝트를 계속 개선해온 이유와 태도
- 문제 발견 → 근본원인 규명 → 검증 → (필요시) 정직한 폐기 → 재도전
  이라는 개발 과정 자체를 하나의 "연구 방법론"으로 설명
- 과거에 내린 결정(iodine 100% 중복 등)도 재검증해서 뒤집은 사례 —
  결론을 고정하지 않고 계속 검증하는 태도
- 하지 않기로 한 것(covalent docking 상시 통합, 경량 캐싱)의 이유를
  설명 — 무엇을 안 하는지도 판단의 결과임
- 오픈소스 공개 계획과 시점
